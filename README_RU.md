# Crowdfunding Escrow на Solana

Децентрализованная платформа для краудфандинга на блокчейне Solana. Создавайте кампании, принимайте взносы и автоматически управляйте сбором средств с помощью смарт-контрактов.

## 🚀 Особенности

- **Безопасность**: Все средства хранятся на PDA (Program Derived Address) до завершения кампании
- **Автоматизация**: Автоматический возврат средств при неудаче кампании
- **Прозрачность**: Все транзакции записываются в блокчейн
- **Децентрализация**: Никакого посредника, только смарт-контракт

## 📋 Функционал

### Для создателей кампаний:
- ✅ Создание кампании с целью и сроком
- ✅ Отмена кампании до окончания срока
- ✅ Получение средств при достижении цели
- ✅ Продление срока кампании

### Для спонсоров (backers):
- ✅ Взнос в любую кампанию (pledge)
- ✅ Возврат средств если цель не достигнута
- ✅ Просмотр всех активных кампаний

## 🛠️ Установка и запуск

### Требования

- **Node.js** >= 18
- **Yarn** >= 1.22
- **Rust** >= 1.70
- **Solana Tool Suite** >= 1.16
- **Anchor** >= 0.30

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd crowdfunding-escrow
```

### 2. Установка зависимостей

```bash
# Frontend зависимости
cd app
yarn install
cd ..
```

### 3. Запуск локального валидатора (опционально)

```bash
# Запуск Solana test validator
solana-test-validator --reset
```

### 4. Сборка и деплой контракта

```bash
# Сборка контракта
anchor build

# Деплой в localnet
anchor deploy

# Или в devnet
anchor deploy --provider.cluster devnet
```

### 5. Запуск frontend

```bash
cd app
yarn dev
```

Frontend доступен по адресу: **http://localhost:3000**

## 💡 Использование

### 1. Подключение кошелька

1. Установите **Phantom Wallet**: https://phantom.app/
2. Переключитесь на **Devnet** в настройках кошелька
3. Получите тестовые SOL: https://faucet.solana.com/
4. Нажмите "Select Wallet" на сайте

### 2. Создание кампании

1. Нажмите **"Создать кампанию"**
2. Заполните форму:
   - Название (до 100 символов)
   - Описание (до 1000 символов)
   - Цель сбора (в SOL)
   - Дата окончания
3. Подтвердите транзакцию в кошельке

### 3. Внесение взноса (Pledge)

1. Выберите кампанию из списка
2. Введите сумму взноса
3. Нажмите **"Внести"**
4. Подтвердите транзакцию

### 4. Получение средств

**Создатель** может получить средства если:
- ✅ Цель достигнута
- ✅ Срок кампании истёк

**Спонсоры** могут получить возврат если:
- ✅ Цель не достигнута
- ✅ Срок кампании истёк
- ✅ Кампания отменена

## 📚 API Смарт-контракта

### Инструкции

| Инструкция | Описание |
|------------|----------|
| `initialize_campaign` | Создать новую кампанию |
| `pledge` | Внести взнос в кампанию |
| `cancel_pledge` | Отменить взнос и получить возврат |
| `claim` | Получить средства (создатель) |
| `cancel_campaign` | Отменить кампанию (создатель) |
| `extend_campaign` | Продлить срок кампании |

### Аккаунты

| Аккаунт | Размер | Описание |
|---------|--------|----------|
| `Campaign` | 1702 байт | Данные кампании |
| `PledgeAccount` | 82 байт | Данные взноса |

## ⚠️ Ограничения

- Максимальная длина названия: **100 символов**
- Максимальная длина описания: **1000 символов**
- Минимальная цель кампании: **0.01 SOL**
- Минимальный взнос: **0.01 SOL**

## 🔐 Безопасность

- Все средства хранятся на **PDA** (Program Derived Address)
- Только создатель может отменить кампанию или получить средства
- Возврат средств возможен только после окончания кампании
- Двойное получение средств невозможно (флаг `is_claimed`)
