# Decentralized Crowdfunding Escrow

Программный прототип для ВКР на тему:

**«Моделирование и реализация механизма условного депонирования для децентрализованных краудфандинговых платформ»**

## О проекте

Проект представляет собой прототип краудфандингового механизма на базе Solana.  
Основная задача — показать, как можно организовать хранение средств спонсоров до завершения кампании и затем выполнить один из сценариев:

- выплатить средства владельцу проекта, если цель сбора достигнута;
- открыть возврат средств, если цель не достигнута.

Также в проект добавлена логика поэтапного финансирования через milestone-механизм. Она позволяет не передавать всю сумму сразу, а распределять средства по этапам после голосования спонсоров. Для спорных ситуаций предусмотрена роль арбитра.

Проект является учебным прототипом и не предназначен для использования с реальными средствами без дополнительного аудита.

## Что реализовано

- создание краудфандинговой кампании;
- внесение средств спонсорами;
- хранение средств в отдельном vault-аккаунте;
- завершение кампании;
- вывод средств владельцем проекта при успешном сборе;
- возврат средств спонсорам при неуспешной кампании;
- отмена кампании;
- продление срока кампании;
- milestone-механизм;
- голосование спонсоров по этапам;
- обработка спорных ситуаций с участием арбитра;
- интеграционные тесты для основных и защитных сценариев.
